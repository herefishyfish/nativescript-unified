# ActivityIndicator and Progress

## ActivityIndicator

Hidden until `busy` is set.

```html live
<ActivityIndicator busy="true"></ActivityIndicator>
```

## Progress

`value` out of `max` (default 100), shown as a bar.

```html live
<Progress value="65"></Progress>
```
